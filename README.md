# AIRFRAME · Flight Club

브라우저에서 즐기는 **SKY RUSH** 드론 아케이드와 기초 조종 훈련입니다. 도시·숲을 날며 링을 연결하고 움직이는 공중 표적을 격파하는 120초 스코어 어택을 제공합니다. 출격하면 설정 패널이 접히고 비행 화면이 크게 열립니다. 상단 **트레이닝**에서는 기존 물리 기반 비행 훈련을 이용할 수 있습니다.

## SKY RUSH 아케이드

[DRONE:AIRFALL](https://droneairfall.com/)의 공개 조작 안내에서 WASD 이동·마우스 조준, 부스터, 고도 유지, FPV, 보급과 전투 피드백을 참고했습니다. 이 프로젝트의 도시·숲 코스에 맞춰 자체 비행 모델과 솔로 점수전을 구현했습니다. 레퍼런스의 코드·이미지·기체 자산을 사용하지 않습니다.

- **스카이라인 / 포레스트 런:** 도시 건물이나 숲의 나무 사이를 통과하는 두 코스.
- **3초 카운트다운 → 120초 비행:** 5m 상공에서 시작. 조준 방향과 고도 제어가 독립적이며, 입력을 놓으면 감속하고 고도를 유지합니다.
- **링:** 순서와 진행 방향에 맞게 통과하면 100점. 12초 안에 다음 링을 연결하면 최대 ×3. 8개를 통과하면 다음 바퀴가 시작됩니다.
- **정밀 통과:** 링 중앙 반경 1.05m 안으로 통과하면 PERFECT +75점, 부스트 중 통과하면 +50점. 두 보너스를 함께 받을 수 있습니다. 링 안쪽 작은 원이 중앙 통과 영역입니다.
- **표적:** 분홍색 공중 표적을 두 발로 격파하면 150점. 5초 안에 다음 표적을 격파하면 연속 격파 보너스가 50점씩 증가하며 최대 +150점입니다. 9초 뒤 재등장합니다. 표적 체력과 명중 가능한 조준점을 표시하며, 지형 뒤의 표적은 맞힐 수 없습니다. 연사를 오래 유지하면 과열되어 냉각해야 합니다.
- **오버드라이브:** 링 +18%(중앙 통과 +26%), 표적 격파 +22%, 크리스털 +8%로 충전합니다. 100%에서 자동 발동하며 8초간 모든 득점 2배·과열 없는 고속 연사·무제한 부스트가 적용됩니다. 발동 중에는 다음 게이지가 쌓이지 않고, 충돌하면 충전량이 20% 줄어듭니다.
- **크리스털:** 개당 25점. 링·크리스털을 획득하면 부스트를 25% 충전합니다. 크리스털 5개마다 실드 하나를 회복합니다.
- **부스트 / 제동:** 기본 최고 속도 9m/s, 부스트 21m/s. 에너지가 바닥나면 25%까지 충전 후 재사용할 수 있습니다. Space로 빠르게 감속합니다.
- **실드 3개:** 장애물·지면·경계 충돌 시 실드 하나를 잃고 밀려납니다. 1.6초 동안 추가 피해를 받지 않으며, 충돌하면 콤보가 초기화됩니다. 실드 소진 또는 시간 종료 시 결과를 표시합니다.
- **피드백:** 우클릭 정밀 조준, 부스트 시야 확장, 속도계, 다음 링 방향 안내와 경로 표시, 명중 표시·표적 체력·파편·충격파·득점 피드. 출격 버튼을 누르면 모터·발사·명중·득점 소리를 시작하며, 소리 버튼으로 끌 수 있습니다. 감도와 소리 설정을 브라우저에 저장합니다. 움직임 줄이기 설정에서는 화면 흔들림과 번쩍임을 줄입니다.
- **기록:** 맵별 최고 점수, 최근 12회, 표적 격파·명중률·중앙 통과·연속 격파·오버드라이브 횟수를 브라우저에 저장합니다. 결과 등급은 D / C(750) / B(1,800) / A(3,500) / S(6,000점)입니다. 새 규칙은 `airframe-rush-v2`에 저장하며 기존 `airframe-rush-v1` 기록을 삭제하지 않습니다.
- **일시정지:** Esc·창 포커스 이탈·탭 전환·마우스 잠금 해제 시 일시정지합니다. 타이머·부스트·과열·카운트다운이 함께 멈춥니다.

| 키 | 아케이드 동작 |
| --- | --- |
| W / S · A / D | 전진 / 후진 · 좌 / 우 이동 |
| 마우스 | 출격 시 마우스 조준 시작. 감도 조절 지원 |
| 우클릭 / V 누르는 동안 | 정밀 조준: 시야 확대·감도 감소 |
| 방향키 | 마우스 없이 시점·조준 |
| Q / E | 상승 / 하강 |
| 좌클릭 / F | 펄스 연사 |
| Shift | 부스트 |
| Space | 급제동 |
| C · R · Esc | 시점 전환 · 재출격 · 일시정지 |

마우스 잠금이 지원되지 않으면 버튼을 누른 채 드래그하거나 방향키로 조준합니다. 좌클릭 드래그는 발사도 함께 수행합니다. 터치 기기에서는 왼쪽 이동 스틱·오른쪽 조준 스틱과 상승·하강·발사·부스트·제동 버튼을 사용합니다. 조준은 FPV와 추적 시점에서 사용할 수 있으며 관찰 시점은 코스를 살펴보기 위한 시점입니다.

충돌은 구형 기체와 상자·구·원기둥·토러스 모양으로 근사합니다. 비행 범위는 반경 72m, 기체 중심 고도 48m입니다. 아케이드는 빠른 반응을 위한 별도 모델이며 아래 훈련 모드의 실제 추력 계산·조작법·착륙 기준과 다릅니다.

## 실행

Node.js 22 이상에서, 별도 패키지 설치 없이 실행합니다. 서버 배포에는 Node.js 24 기반 Docker 이미지를 제공합니다.

```sh
npm start
```

기본 수신 주소는 `0.0.0.0:7175`입니다. 실행한 컴퓨터에서는 http://127.0.0.1:7175, 서버 컴퓨터의 IP가 `192.168.0.7`이면 같은 네트워크에서 http://192.168.0.7:7175 로 접속합니다. `HOST`·`PORT` 환경 변수로 변경할 수 있습니다. 로컬 개발에서만 열려면 `HOST=127.0.0.1 PORT=4173 npm start`로 실행하세요(macOS/Linux).

**상시 서버 운영:** [서버 배포 안내](DEPLOY.md)에 따라 `docker compose up -d --build --wait`를 실행하세요. 백그라운드 실행, 프로세스 종료 시 자동 재시작, Docker 시작 시 복구, 상태 확인, 로그 용량 제한이 설정되어 있습니다. `npm start`만 실행하면 터미널 종료·재부팅 후 자동 실행되지 않습니다. ES 모듈과 WebGL 2를 사용하므로 HTML 파일 더블클릭으로는 실행되지 않습니다.

WebGL 2 지원 브라우저가 필요합니다. 아케이드는 키보드·마우스·터치 조종을 지원하고, 트레이닝에는 키보드가 필요합니다. Three.js는 저장소에 포함되어 있으며 외부 CDN에 의존하지 않습니다. 외부 Google Fonts를 사용할 수 없으면 시스템 글꼴로 표시됩니다.

## 트레이닝 조종법

GTA 스타일 키보드 배치를 쿼드콥터 조종에 맞게 구성했습니다. GTA의 고정익 비행 역학을 복제한 것은 아닙니다.

| 키 | 동작 |
| --- | --- |
| W / S | 상승 / 하강. 수동 추력에서는 추력 설정 증가 / 감소 |
| A / D | 기수를 왼쪽 / 오른쪽으로 회전 (요) |
| ↑ / ↓ 또는 숫자패드 8 / 5 | 기수 숙이기 / 들기 (피치) |
| ← / → 또는 숫자패드 4 / 6 | 좌 / 우 기울이기 (롤) |
| Shift + 조종 키 | 입력 강도를 25%로 줄여 미세 조종 |
| Space 누르는 동안 | 임시 위치·고도 보조. 기록에 개입 횟수와 시간 표시 |
| C | 추적 → FPV → 관찰 시점 |
| Esc | 일시정지 / 계속 훈련 |
| R | 현재 훈련 처음부터 다시 시작 |

입력은 `KeyboardEvent.code`를 사용해 한글 입력 상태에서도 물리 키 위치를 기준으로 동작합니다. 창 포커스를 잃거나 다른 탭으로 이동하면 입력을 초기화하고 자동 일시정지합니다.

## 비행 보조 단계

| 모드 | 수평 제어 | 수직 제어 | 키를 놓으면 |
| --- | --- | --- | --- |
| 위치 보조 / POS | 기체 기준 속도 명령, 위치 제어 | 상승·하강 속도, 고도 제어 | 제동 후 위치와 고도 유지 |
| 자세 모드 / ATTI | 롤·피치 각도 명령 | 상승·하강 속도, 고도 제어 | 수평·고도 회복, 수평 관성과 바람의 영향은 남음 |
| 수동 추력 / STAB | 롤·피치 각도 명령 | 모터 추력을 직접 증감 | 수평 회복, 선택한 추력은 그대로 유지 |

수동 추력은 ACRO가 아닙니다. 자세 안정화는 계속 작동합니다. 무풍에서 수평 호버 추력은 약 43%이며, 기체를 기울이면 수직 추력 성분이 줄어 고도가 내려갑니다. Space는 즉시 순간이동하거나 속도를 0으로 만드는 기능이 아니라 위치 제어기를 통한 제동입니다.

비행 모드 개념은 [PX4 Position](https://docs.px4.io/main/en/flight_modes_mc/position)과 [PX4 Altitude](https://docs.px4.io/main/en/flight_modes_mc/altitude)를 참고했습니다. 실제 PX4 펌웨어를 실행하거나 제어 로직·파라미터를 그대로 복제하지 않습니다.

## 훈련

1. **이륙과 호버링**: 지면에서 직접 이륙. 고도 5m ±0.5m, 원점 반경 1.5m, 속도 0.7m/s 미만, 기울기 8° 미만으로 연속 10초 유지. 이탈하면 유지 시간이 초기화됩니다.
2. **자세와 방향 제어**: 5m 상공에서 시작. 우측 롤 → 수평·정지 → 전방 피치 → 수평·정지 → 동쪽 기수 90°를 차례로 수행합니다.
3. **사각 경로 비행**: 5m 상공에서 시작. 한 변 12m의 사각 경로를 순서대로 이동하며 각 꼭짓점에서 2초 정지합니다. 기수는 북쪽 ±15°로 유지합니다.
4. **정밀 착륙**: 8m 상공에서 시작. 패드 반경 1.2m, 하강 속도 0.8m/s 이하, 수평 속도 0.6m/s 이하, 기울기 8° 이하로 착지합니다.
5. **자유 연습**: 별도 완료 조건 없이 비행합니다. 훈련 종료 버튼으로 기록을 남깁니다.

무풍·1.5m/s·3m/s와 돌풍을 선택할 수 있습니다. 바람은 동쪽·북쪽 방향 성분을 가진 자체 모델이며 날씨 API를 사용하지 않습니다. 원점 반경 75m, 최대 고도 50m를 벗어나거나 강한 착지·장애물 충돌이 발생하면 훈련을 종료합니다. 각 정규 훈련은 최대 5분입니다.

결과에는 실제 비행 궤적, 고도 변화, 고도 RMS 오차, 보조 개입, 착륙 시 속도·중심 오차가 표시됩니다. 고도 RMS는 호버링·자세·사각 훈련에서 고도 3m 이상인 동안 5m와의 오차를 계산합니다. 보조를 사용하지 않은 완료에만 목록의 완료 표시가 붙습니다. 최근 12회 기록을 브라우저 로컬 저장소에 보관하며, CSV를 내려받을 수 있습니다. 저장된 과거 비행의 샘플은 최대 240개로 줄여 보관합니다.

## 비행 모델과 범위

- 1/120초 고정 시간 간격, SI 단위, Y축 상향 좌표계
- 질량 1.15kg, 각 모터 최대 추력 6.6N, 모터 간 반폭 0.24m
- 쿼터니언 자세 적분, 강체 관성 및 자이로 항, 자세·각속도 제어
- 쿼드 X 모터 추력 배분과 55ms 모터 응답 지연
- 기체 자세에 따른 추력, 중력, 상대 공기 속도에 따른 저항과 바람
- 구형 기체 근사와 상자 장애물 충돌, 지면 접촉 속도·기울기 판정

학습용으로 설정한 가상의 기체입니다. 실제 기체의 센서 잡음·추정 지연·지면 효과·프로펠러 공력·배터리 전압 변화·구조 변형·비행제어기 펌웨어는 재현하지 않습니다. 특정 제품이나 자격시험용 인증 시뮬레이터가 아닙니다. 충돌 범위는 단순화되어 있습니다. 훈련장의 나무·펜스는 배경 장식이지만, 아케이드 맵의 나무 줄기·수관에는 충돌 판정을 적용합니다.

- `sim/scene.js`: Three.js 장면과 카메라
- `sim/maps.js`: 도시·숲 코스, 아이템, 장애물 배치
- `sim/arcade.js`: 공통 링·콤보·수집 규칙
- `sim/arcade-flight.js`: 아케이드 이동·고도 유지·부스트·실드
- `sim/arcade-input.js`: 마우스 잠금·드래그·터치 스틱
- `sim/rush.js`: 120초 점수전·정밀 통과·연속 격파·오버드라이브·조준 판정·결과 등급
- `sim/rush-scene.js`: 공중 표적·체력 표시·펄스·파편·충격파 효과
- `sim/collision.js`: 장애물 충돌·링 통과·아이템 수집 판정
- `sim/arcade-scene.js`: 도시·숲과 링·크리스털 렌더링
- `app.js`: 입력, HUD, 그래프, 결과·로컬 저장
- `server.mjs`: 아케이드·훈련 정적 파일과 상태 확인 제공
- `tests/`: 아케이드·비행 모델·훈련 기준·서버의 동작 검증
- `three` 0.186.0: npm 의존성. 브라우저는 `index.html`의 import map으로 빌드 파일만 불러온다

```sh
npm test
```

```jsx
<iframe
  title="AIRFRAME 드론 비행 훈련"
  src="/airframe/index.html"
  allow="fullscreen"
  style={{ width: '100%', height: '1250px', border: 0 }}
/>
```

프레임 안에서 훈련을 시작하면 키보드 포커스를 얻습니다. 독립 엔진으로도 분리되어 있으므로 추후 React의 생명주기와 연결할 수 있습니다. 현재는 iframe 경로가 제공된 통합 방식이며 React 컴포넌트의 마운트·언마운트 API는 구현하지 않았습니다. 완료 시 프레임 내부 `window`에서 `airframe:training-complete` CustomEvent를 발생시키며, 부모 프레임 전달은 추가 연결이 필요합니다.

## 교육용 발전 방향

권장 흐름은 **무풍 + 위치 보조 → 무풍 + 자세 모드 → 약풍 + 자세 모드 → 수동 추력**입니다. 다음으로 우선할 기능은 USB 조종기/게임패드의 아날로그 입력·축 보정과 교관용 비행 리플레이입니다. 키보드는 조종 원리 학습에 편하지만 실제 송신기의 스틱 감각까지 전이시키기에는 한계가 있습니다.
